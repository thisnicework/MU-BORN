# 2026 MU:BORN 공식 웹사이트

서울예술대학교 학사학위 창작뮤지컬 개발 과정 **MU:BORN 2026** (`<다이노즈>` & `<세상 모든 이야기의 끝>`) 공식 웹사이트입니다.  
**Vite + React + TypeScript + Tailwind CSS v4 + Node SQLite API** 기반으로 구성되어 있습니다.

## 주요 기능

- **MAIN (`/`)**: DINOZ 공식 트레일러 풀스크린 히어로 영상, 2개 작품 티켓 오픈 안내, 2026 MU:BORN LINE UP 포스터 쇼케이스, 포토이즘 프레임 배너, 공식 협찬사(비브온·비소리), 공식 인스타그램(`@sia.bfa.muborn`) 연동
- **MU:BORN (`/muborn`)**: MU:BORN 소개, 2026 라인업, 기획의도, 2016–2026 MU:BORN HISTORY 포스터 아카이브 (라이트박스 지원)
- **작품 상세 페이지**:
  - **창작뮤지컬 `<다이노즈>` (`/works/dinoz`)**: 외계 아이돌 데뷔 콘셉트 다크 테마, 트레일러, 공연 정보, 시놉시스, 연출·작가 노트, 캐스트(DINOZ 3+1 구도 / Performer 2+3 구도)
  - **창작뮤지컬 `<세상 모든 이야기의 끝>` (`/works/semokkeut`)**: 동화책 감성 웜 테마, 공연 정보, 시놉시스, 연출·작가 노트, 캐스트(해원·리브·정목 3열 구도)
- **티켓 예매 (`/tickets`)**:
  - ① `<다이노즈>` (2026.11.22. 20:00 오픈) / ② `<세상 모든 이야기의 끝>` (2026.12.03. 20:00 오픈 예정)
  - 전화번호 2회 재입력 확인으로 오타 방지
  - 회차별 1인 1매 · 복수 회차 개별 조합 선택 가능 (예: 1+3회차, 1+2+3회차)
  - 동일 연락처 동일 회차 중복 예매 차단 및 SQLite 트랜잭션 동시성 제어
  - 최대 수량(67/114/112매) 및 잔여 수량은 일반 예매 페이지에 노출되지 않으며 관리자 페이지에서만 확인 가능
  - 예매 내역 조회 및 취소 지원
- **CREATIVE TEAM (`/creative-team`)**: `<다이노즈>`(45명) / `<세상 모든 이야기의 끝>`(46명) 파일명 번호순 프로필 갤러리, 파트별 필터·검색, 공식 크레딧 이미지 및 텍스트 크레딧
- **관람 안내 (`/guide`)**: Audience Guide, Ticket Receipt, On-site Ticket, 공연장(남산 드라마센터 / 서울예술대학교 빨간대문) 지도 링크, 공식 협찬사
- **MU:BORN 포토이즘 (`/photobooth`)**: `<다이노즈>`, `<세상 모든 이야기의 끝>`, `MU:BORN 2026` 4컷 포토이즘 프레임 생성기 (배우 프로필 합작 모드, 웹캠 4컷 촬영, 사진 업로드, 고화질 PNG 저장)

## 실행 방법

```bash
# 개발 서버 실행 (Vite + 내장 SQLite API 미들웨어, 단일 포트 http://localhost:5173)
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행 (dist/ 정적 서빙 + /api/* SQLite 서버, 기본 포트 3000)
ADMIN_PASSWORD=원하는비밀번호 PORT=3000 npm start
```
